Capstone Project

Project Summary

90Mins — Football Live Score Web Application

Course: COMP 3078 — George Brown Polytechnic  |  Winter 2026

90Mins is a full-stack football live score web application that delivers real-time match data, league standings, and team statistics. The application allows users to track live matches, browse upcoming fixtures across major European leagues, save favourite teams, and receive match reminders through an integrated notification system. The project was developed over eight sprints using an Agile methodology, with the frontend deployed to Vercel and the backend hosted on Render.

Project Vision

To build a reliable, responsive, and user-centred football data platform that aggregates live scores and fixture information from top leagues worldwide, giving fans a single destination for real-time match tracking. The platform prioritizes performance, accessibility, and a clean user experience across both desktop and mobile devices delivering data under 500ms response times with page loads under 3 seconds.

Project / Business Requirements

  • Display live match scores with automatic data refresh every 30–60 seconds
  • Support filtering by league (Premier League, La Liga, Serie A, Bundesliga, Ligue 1)
  • Provide league standings tables with up-to-date points, wins, draws, and losses
  • Allow authenticated users to save and manage favourite teams
  • Send match reminder notifications to registered users
  • Deliver API response times under 500ms and page loads under 3 seconds
  • Achieve a minimum of 60% automated test coverage
  • Support responsive design across 320px to full desktop viewport widths
  • Deploy to a publicly accessible production environment with an active expiry date beyond semester end
